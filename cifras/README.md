# Pasta de cifras

Coloque aqui os arquivos `.txt` das suas cifras (um arquivo por música).

## Como nomear

O nome do arquivo vira o título na lista. Use o formato:

```
Artista - Nome da Música.txt
```

Exemplos:
- `Legião Urbana - Tempo Perdido.txt`
- `Djavan - Oceano.txt`

Se não usar o ` - `, o nome inteiro vira o título.

## Formato do conteúdo

Texto simples, no estilo do CifraClub: os acordes ficam numa linha, a letra
na linha de baixo. O app detecta automaticamente as linhas de acordes e
permite transpor o tom. Marcações entre colchetes viram títulos de seção:

```
[Intro]  C  G  Am  F

C                 G
Primeira linha da letra
Am                F
Segunda linha da letra
```

Não precisa reiniciar o servidor ao adicionar arquivos — é só atualizar a
página no iPad.
